# Contributing

Bug reports, ideas and pull requests are welcome, in English or Spanish.

## Setup

```bash
pip install -e . pytest
pytest
```

## Pull requests

- One feature or fix per pull request, with tests.
- No runtime dependencies: the library uses only the standard library.
- For dates and official rules (holidays, DIAN, DANE), link the source you used in the pull request.
- Use public or made-up data in tests: never real personal IDs or phone numbers.

Planned work is in [ROADMAP.md](ROADMAP.md) and the open issues.
